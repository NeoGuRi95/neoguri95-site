# neoguri95

`neoguri95.com`은 글을 발행하고 방문자가 새 글 알림을 구독할 수 있는 개인 사이트입니다.

## 주요 기능

- **글:** 홈에서 발행된 글을 확인하고 본문을 읽습니다.
- **이메일 구독:** 이메일 주소를 입력하고 확인 메일의 링크에서 구독을 확정합니다.
- **새 글 알림:** 글이 발행되면 구독자에게 이메일을 보냅니다. 발송 실패는 재시도합니다.

화면은 `site-app`이 Spring MVC와 Thymeleaf로 렌더링합니다. `email-app`은 구독 확인 메일과 새 글 알림을 발송합니다.

글 발행 및 구독 상태 변경과 이벤트 기록은 한 DB 트랜잭션으로 처리합니다. Debezium이 outbox 테이블의 변경을 읽어 Kafka에 발행하고, `email-app`이 이벤트를 소비합니다. Transactional Outbox로 DB 변경과 이벤트 기록의 불일치를 막고, 재전달된 이벤트는 중복 처리하지 않습니다.

화면과 기능 규칙은 [제품 설계](docs/design.md), 로컬 실행과 CDC 구성은 [개발 메모](docs/architecture.md)에 정리했습니다.
