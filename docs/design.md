# 제품 설계: neoguri95

## 목표

`neoguri95.com`에서 글을 발행하고 방문자가 이메일로 새 글 알림을 받는다.

## 방문자 동선

| 화면 | 내용 | 경로 |
|---|---|---|
| 홈 | 소개, 새 글 목록, 이메일 구독 폼 | `/` |
| 글 | 제목과 본문 | `/posts/{id}` |
| 구독 확인 | 확인 메일 링크를 열어 구독 확정 | `/subscriptions/confirm?token=...` |

방문자가 이메일을 제출하면 구독 상태를 `PENDING`으로 저장하고 확인 메일을 요청한다. 링크를 열고 확인 버튼을 누른 뒤에만 `ACTIVE`로 바꾼다. 확인 링크는 24시간 동안 유효하다. 같은 이메일의 중복 요청은 구독을 중복 생성하지 않는다. 새 글 메일에는 구독 해지 링크를 넣는다.

운영자가 글을 발행하면 글과 `PostPublished` 이벤트를 함께 저장한다. 이메일 앱은 확정된 구독자에게 새 글 제목과 링크를 보낸다. 발송은 글 게시 화면의 응답을 지연시키지 않으며, 실패한 작업은 재시도한다.

## 관리와 운영

글 발행 API는 관리자 토큰으로 보호한다. 공개 운영 전에는 비밀값을 별도로 설정하고 관리자 인증을 보강한다. 메일 주소는 알림 발송 목적으로만 사용한다.

CDC를 통해 이벤트가 다시 전달될 수 있으므로 이메일 앱은 이벤트 ID로 중복 처리를 막는다. 메일 서버가 수락한 직후 앱이 종료되면 실제 이메일은 중복 발송될 수 있다.

내부 이벤트와 로컬 실행 방법은 [개발 메모](architecture.md)에 정리했다.
